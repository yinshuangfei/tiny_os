# x86 参数传递
x86 32 位 cdecl (C Declaratio, C 语言声明) 约定：

- 参数由 caller 从右到左 push
- callee（swtch）不替参数压栈
- 返回后通常由 caller 自己 add esp, 8 清参数（若需要）
所以 old、new 两个指针是 sched() / scheduler() 在 call 之前 压上去的。

- 32 位系统（x86）
在传统的 32 位系统中，由于通用寄存器数量太少（只有 8 个，且部分有保留用途），绝大多数情况都使用栈来传递参数。
    - C 语言默认调用约定 (cdecl)：
    - 所有参数从右向左依次压入栈中。
    - 由调用者负责在函数返回后清理栈。

- 64 位系统（x86-64 / AMD64）
在现代 64 位系统中，为了提高性能，寄存器传参是主流。
Linux / macOS (System V AMD64 ABI)：
    - 前 6 个整数/指针参数依次使用：rdi, rsi, rdx, rcx, r8, r9。
    - 前 8 个浮点数参数使用：xmm0 到 xmm7。
    - 只有当寄存器用尽，或者参数太大（如结构体）时，才会使用栈。
