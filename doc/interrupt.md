BIOS 中断只在 16 位实模式 下有效。一旦你的代码通过 lgdt 和 movl %cr0, %eax 切换到 32 位保护模式，这些 int $xx 指令就会失效。在保护模式下，你需要直接操作硬件端口（如 VGA 显存 0xB8000、ATA/IDE 端口）或者编写自己的驱动程序。

在 x86 实模式下，BIOS 提供了一系列中断服务（Interrupts），它们通过不同的中断号（Interrupt Number）来区分功能。以下是你在编写引导扇区（Bootloader）时最常用到的几个核心 BIOS 中断：
1. int $0x10：视频/显示服务 (Video Services)
这是最常用的中断之一，主要用于在屏幕上输出字符、设置显示模式等。
AH = 0x00：设置视频模式（例如 AL=0x03 是 80x25 文本模式）。
AH = 0x0E：在光标位置打印一个字符（TTY 模式），要打印的字符放在 AL 寄存器中。
AH = 0x02：设置光标位置（DH=行, DL=列, BH=页码）。
2. int $0x13：磁盘 I/O 服务 (Disk Services)
正如你之前代码中使用的，用于读写软盘或硬盘。
AH = 0x02：读取扇区。
AH = 0x03：写入扇区。
AH = 0x08：获取当前驱动器的参数（柱面、磁头、扇区数等）。
3. int $0x16：键盘服务 (Keyboard Services)
用于读取键盘输入，这在 bootloader 中实现“按任意键继续”时非常有用。
AH = 0x00：阻塞等待并读取下一个按键（结果存入 AL=ASCII码, AH=扫描码）。
AH = 0x01：检查键盘缓冲区是否有按键（如果有，ZF=0；如果没有，ZF=1）。
4. int $0x15：系统/内存服务 (System Services)
AH = 0xE820：获取系统内存映射表（Memory Map）。这是现代操作系统内核启动前必须调用的中断，用于知道物理内存的分布情况。
AH = 0x88：获取扩展内存大小（较老的方法，最大只能获取 64MB）。
5. int $0x12：获取常规内存大小
不需要设置 AH，直接调用。返回值在 AX 中，表示常规内存（前 1MB 内）的大小，单位是 KB。
6. int $0x20：程序终止
在 DOS 环境下用于正常退出程序。在裸机 bootloader 中通常不用。
