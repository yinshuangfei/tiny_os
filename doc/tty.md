# tty0 和 ttyS0
tty0 和 ttyS0 是 Linux 系统中两种不同类型的终端设备，分别代表虚拟控制台和物理串行端口。

- tty0：这是 Linux 的虚拟控制台设备，通常对应于系统启动时默认显示的本地终端界面。它不是物理硬件，而是由内核模拟的“屏幕+键盘”接口。在图形界面未启动时，你可以通过 Ctrl+Alt+F1~F6 切换到 tty1~tty6，而 tty0 通常指代当前激活的虚拟终端。它常用于本地调试、系统恢复或无图形环境下的操作。
- ttyS0：这是第一个物理串行端口（Serial Port），对应于传统 PC 上的 COM1 端口。它用于连接外部串口设备，如调制解调器、工业控制器、嵌入式开发板（如树莓派、Jetson TX2）或调试线。在嵌入式系统中，ttyS0 常被配置为内核控制台，用于输出启动日志和接收命令行输入，例如通过 console=ttyS0,115200 内核参数指定。


# vga 中，制表符占几个字符？
在标准的 VGA 文本模式下，制表位默认是每 8 个字符设置一个。
